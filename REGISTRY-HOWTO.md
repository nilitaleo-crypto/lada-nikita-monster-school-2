# Добавление новых игр в Тиввиг — единый реестр

Реестр: [game-registry.js](game-registry.js). В нём находятся **все страницы, названия, навигация преподавателя и ключи наград**. Скрипты `coop.js`, `world-coop-bridge.js`, карта и коллекция считывают этот реестр — не нужно поддерживать четыре разных списка.

## Как каждый день добавлять новую игру

1. Создать `new-game.html` в корне сайта (рядом с `index.html`), со своими стилями, картинками и игровыми правилами.
2. В `game-registry.js` добавить одну запись `pages`: `{path:"new-game.html",title:"Название",menuLabel:"🎲 Название"}`. Чтобы новая игра открывалась при нажатии на область карты, поставить `entry:true` и `region:"ladaburg"` (или другой известный регион).
3. Перед игровым JavaScript подключить `<script src="game-registry.js"></script>`, а в конце страницы `<script src="world-coop-bridge.js" defer></script>`.
4. При необходимости награды добавить запись в массив `rewards`, например `{key:"tivvig_reward_ladaburg_stars_v1",gallery:true,autoGallery:true,id:"stars",title:"Небесные звёзды",image:"images/stars.webp",game:"new-game.html"}`. Вызывать `window.TivvigRegistry.unlockReward("tivvig_reward_ladaburg_stars_v1")` при победе. **Она автоматически появится в альбоме и будет передана в Firebase.**

Поскольку GitHub Pages использует браузерное кэширование, после добавления игры обнови вкладки на компьютере и iPad. Для игровой логики с обычными `<button>` или `<a>` дополнительная настройка синхронизации не требуется. Перетаскивание, рисование или сложные действия всё ещё требуют специальных обработчиков.

## Настройка Firebase — один раз

После введения реестра опубликовать содержимое [firebase.database.rules.json](firebase.database.rules.json) в Firebase Console → Realtime Database → Rules → Publish. Эти правила разрешают **только ключи наград заданного шаблона**, поэтому добавлять каждый новый приз в правила Firebase ежедневно не нужно. Старые награды и коллекция сохраняются.

Доступ к постоянному профилю Лады остаётся только у Google-аккаунта преподавателя, а ребёнок может пользоваться приглашённой комнатой. **Коммит в GitHub не меняет настройки Firebase автоматически.**

## Ладабург: Десять чудес

Игра `ladaburg-baby.html`: две иллюстрации Лады (без малыша и с малышом). После десятого нажатия показывается второй портрет, сохраняется ключ `tivvig_reward_ladaburg_baby_v1`; новая карточка автоматически появляется в коллекции. Кнопка «Ещё раз» позволяет переиграть, не сбрасывая сохранённую награду.

### Приватность

Фотографии в `images/ladaburg-before.webp` и `images/ladaburg-after.webp` являются изображениями ребёнка. GitHub Pages — **публичный сайт**; эти картинки видны любому человеку с URL. Если понадобится приватный доступ, нужно перевести картинки в закрытое хранилище с авторизацией, а не держать их в публичном репозитории.

### Откат

Рабочая версия до создания реестра сохранена в `stable/2026-11-05-firebase-working`. Текущие изменения сначала разрабатывались в `feature/unified-games-registry-ladaburg`.
