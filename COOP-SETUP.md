# Совместный режим Тиввига — GitHub Pages

**Основной и единственный рабочий адрес:** https://nilitaleo-crypto.github.io/lada-nikita-monster-school-2/

**Совместное занятие:** https://nilitaleo-crypto.github.io/lada-nikita-monster-school-2/coop.html

Исходный код находится в ветке `main`. Раньше Firebase-режим проверяли в Netlify Deploy Preview, но теперь он включён в основной сайт GitHub Pages. Для занятий ссылка Netlify больше не нужна.

## Как начать занятие

1. Преподаватель открывает `coop.html` на компьютере, входит через Google, нажимает «Скопировать ссылку» и отправляет приглашение ребёнку.
2. Ребёнок открывает **именно пригласительную ссылку** в Safari на iPad и нажимает «Я Лада — войти в игру». Email ребёнку не требуется.
3. Оба остаются внутри `coop.html`: игровые страницы открываются во встроенном игровом окне, не в самостоятельной вкладке.
4. Переходы по карте, в лес Майкла Джексона, вулкан, коллекцию и гардероб синхронизируются через Firebase Realtime Database. Обычные игровые клики передаются обоим браузерам. Красная точка преподавателя и синяя точка ученицы находятся в постоянной оболочке занятия.
5. В лабиринте преподаватель рисует подсказку, а ребёнок ведёт свою линию; это отдельная механика, не буквальное копирование каждого жеста.

## Настройка Firebase для домена GitHub Pages

**Действия в Firebase Console обязательны: коммит в GitHub не публикует настройки Firebase.**

1. В [Authentication → Settings → Authorized domains](https://console.firebase.google.com/project/tivvig/authentication/settings) добавьте `nilitaleo-crypto.github.io` (без протокола, пути и косой черты).
2. Проверьте, что в Authentication → Sign-in method включены Google (для преподавателя) и Anonymous (для ребёнка).
3. Откройте [Realtime Database → Rules](https://console.firebase.google.com/project/tivvig/database/tivvig-default-rtdb/rules), замените прежние правила полным содержимым файла [firebase.database.rules.json](firebase.database.rules.json) из `main`, нажмите **Publish**. Не используйте общедоступные `.read: true` или `.write: true`.

## Диагностика

- **Курсор виден, но игра не переходит**: проверить публикацию Rules; нажатия и общая страница — отдельные пути RTDB.
- **Переход срабатывает только у одного**: проверьте, что обе стороны находятся в одной комнате `coop.html`, а не в отдельных адресах `index.html` или игр.
- **Google вход отклонён**: проверьте Authorized domains.
- **Старые скрипты в браузере**: закройте прошлые вкладки, откройте новый адрес `coop.html` и создайте новую комнату.
- **Кнопки не реагируют**: проверьте сообщение под игрой и строку состояния загрузки. После локальной загрузки экран ожидания не должен перекрывать игровое поле.
- **Награды и наряды**: сохраняются в браузере и синхронизируются в комнате; для полной межустройственной истории понадобится дополнительное тестирование.

## Ограничения

Это синхронизация игровых событий внутри Тиввига, **не видеотрансляция экрана iPad**. В сложных играх, анимациях и после повторного подключения возможны различия в промежуточных состояниях; отладка на двух реальных устройствах обязательна. Публикация GitHub Pages и проверка исходного JavaScript сами по себе не подтверждают корректную работу Firebase-сессии.

## Код

- `coop.html` — общий интерфейс занятия.
- `coop.js` — Firebase, маршрутизация, общие действия, курсор, награды.
- `world-coop-bridge.js` — передача игровых нажатий, переходов, позиции курсора из отдельных страниц.
- `maze-coop-bridge.js` — подсказки и прогресс лабиринта.
- `firebase.database.rules.json` — ограниченные разрешения для совместной комнаты.
